# 人物与社会模拟 V2

LabX 的本地虚拟社会实验。人物共同竞争岗位、培养名额与合作时间，家庭、企业、学校和公共部门分别结算资金。默认观察人物从十五岁开始，其他成员具有不同年龄；六十岁是默认观察终点，人物可以继续生活和工作。

所有 `synthetic-v2` 参数均为**未标定的合成假设**。人物决策、信念、情绪、记忆更新和实验均不调用大模型或外部测评服务。现实解释力需通过后续独立数据验证获得。

## 本地运行

需要 Node.js 20.19+ 或 22.12+，推荐 Node.js 24。

```bash
npm install
npm run dev
npm test
npm run build
```

打开终端显示的地址。构建产物包括 `dist/` 和 `outputs/MBTI人生模拟.html`。后者内联页面、样式和 Worker，可离线打开。浏览器限制本地文件持久存储时，可导出 JSON，或通过本地服务使用档案库。

## 观察一个社会

1. 配置世界种子、初始人口、月份、人格模型与最多十六名观察人物。默认一千人、四百户、三地区、六所培养机构和三十六家企业；“先运行 80 人 · 24 月”用于检查流程。
2. 计算在 Web Worker 中进行。播放、拖动游标、筛选、查看原因均读取已经生成的记录。
3. 人生观察展示实际选择、可行候选、时间成本和反馈。研究者事实与人物自己的观察分别显示。
4. 发展档案分别展示知识、实践、作品、情绪、主观信念和更新记录。八维与大五独立采样；无人格版本关闭人格偏好效应。
5. 平行社会从选定月份恢复整个世界，再修改处罚政策与学习开关。比较个人变化与群体溢出，可以跳转一年或五年后。
6. 社会账本展示实际流水、欠款和现金恒等式；期末全世界账户与历史游标数据明确区分。
7. 本地档案保存压缩的年度世界检查点和观察轨迹。完整世界 JSON 可迁移来源；观察 HTML 仅含截至当前月份的已知事件。

V1 单人人生在本地档案中只读保留，可复用其十五岁初始配置新建 V2。旧的中途快照不能转换成完整社会。

## Node 批量实验

```bash
# 小规模检查十二条件实验与四个并行工作线程
npm run experiment -- experiment --smoke --workers 4

# 正式默认：千人；30 个独立世界重复；120 月预热；60 月干预观察
npm run experiment -- experiment --workers 4 --out outputs/formal

# 中断后只恢复已经完整保存的独立重复；也可传入完整或中间报告 JSON
npm run experiment -- experiment --resume outputs/formal --out outputs/formal-resumed

# 单世界：完整事件、账本、群体表、年度检查点和完整观察档案
npm run experiment -- run --model none --months 540 --out outputs/world

# 六维 64 点拉丁超立方，随后对前两项做 5×5 网格
npm run experiment -- sensitivity --points 64 --months 60

# 固定、仅信念、信念加习惯、开启人格可塑性，四种结构配对对照
npm run experiment -- structure --model jung8 --seeds 30 --warmup 120 --months 60

# 对外部提供的二元结果预测进行家庭留出评估
npm run experiment -- validate --input predictions.json --future-after 24
```

通用参数有 `--seed`、`--population`、`--out` 和 `--parameters 参数覆盖.json`。`--smoke` 的人口与时长较小，只验证执行流程。`run` 默认输出完整 `events.ndjson` 和 `ledger.ndjson`；实验加 `--events` 可导出完整流，此时按顺序执行，不能从只有指标的报告补造旧事件。

十二条件为三个人格模型 × 处罚倾向 `.2/.8` × 信念学习开/关。相同人格模型内从共同的完整预热快照分支，处理期锁定政策并关闭习惯与机构学习。结果按世界种子配对估计，人物不作为独立重复。报告分别提供处理一年与终点的均值差、标准误、95% 蒙特卡洛区间，包含正确/错误报告构成与离职/录用人次。只有一个重复时不提供区间。

每次命令保存冻结的 `kernel.mjs`、带源码的源映射、SHA-256、参数与运行清单。已完成的独立重复另存为 `replicate-*.json`，用于安全续跑。续跑要求规则版本、冻结内核 SHA 和实验配置相同，不能混入旧规则结果。完整产物位于 `outputs/`，不纳入 Git。

## 外部数据与计算契约

- 金额为整数分；余额非负，工资、学费等欠款单列。内部转移不改变社会现金，外部购买和外部消费有明确边界。
- 时间最小半小时；每月四子步，健康限制每个子步最多八十小时，照料先占用时间。
- 知识、实践、状态及大五为 `0—1`；八维原始分数为 `0—100`。人格不直接进入原始任务质量公式。
- 决策只接收人物观察；研究者事实、未来外生事件、他人真实画像不进入观察对象。
- 宏观输入可在配置中给出 `macroSeries`，指定月份的需求系数、物价、分区行业系数和明确拨款。`exogenousEvents` 可预登记出生、健康、死亡与迁移冲击。人物不能提前读取这些输入。
- `predictions.json` 是包含 `householdId, month, outcome, probability, baselineProbability, weight, target, aligned?` 的数组。验证接口按家庭固定分组，并排除用于强制对齐的样本；预测来源、训练时期和参数估计仍需另外审计。

人口初始分布、人格矩阵、行为与管理强化机制都属于可替换的合成假设。小人口模式对名额和岗位设置了最小整数容量，不能将其人均结果直接当作千人世界的缩放结果。首版合作实际匹配为双人任务，贡献按移除成员后的质量变化计算，外界记功独立保存。

## 本次工程验证

58 项自动测试、生产与离线构建通过。Chrome 与 Node 的完整世界、指标、轨迹和事件逐值一致；千人 540 月逐月资源检查及现金恒等式通过。80 人十二条件 × 30 世界重复、断点续跑、64+25 敏感性及四结构流程已验证。完整千人 30 重复正式研究及现实数据标定未在本轮完成。
