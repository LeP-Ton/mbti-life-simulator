# MBTI 人生模拟

GameX / LabX 的中文版自动人生模拟游戏。人格是故事的起点，学习、实践、选择与环境共同留下不同轨迹。

## 运行

需要 Node.js 20.19+ 或 22.12+，推荐 Node.js 24。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。使用 `npm run build` 做类型检查与生产构建，使用 `npm run preview` 预览 `dist/`。Windows 若限制 PowerShell 脚本，可使用 `npm.cmd` 替代 `npm`。

```bash
npm test
```

测试使用 Node 内置测试运行器与 tsx，覆盖八维推导、确定性、跨阶段闭环、时间约束、身份与筛选分离、因果链接、真实快照分支及 HTML 导出边界。

## 自动玩法

1. 可直接播放默认人物，或点击“新的人生”配置姓名、身份、家庭与环境。
2. 八维支持随机、目标类型采样、手动调整。实际类型始终由完整八维推导。
3. 点击“开始人生”后，人物自己学习、安排自主时间、选择升学路径、求职、协作与继续学习；不需要玩家回答人生选择题。
4. 可暂停、切换 1 / 3 / 12 / 36 倍播放、拖动月份、跳到转折或阶段末，也可瞬时查看六十岁总结。
5. 展开“查看原因”读取发生条件、候选选择、机会成本、原始表现、评价与前因；前后两个月可直接定位。
6. “发展档案”自动汇总成绩、资格、作品、知识、练习与关系。全部内容来自当前月份的真实记录。
7. “平行人生”支持同人换环境、同起点换类型、同类型换起点、同配置换种子；两个视图同步月份。观察室最多十六名人物。
8. 保存时可命名档案，星标用于收藏。本地存档使用 IndexedDB，刷新后可恢复播放位置。
9. 可导出截至当前月份的独立 HTML 人生年表，或完整 JSON 数据。HTML 可直接分享、离线展开因果、打印或另存为 PDF。

“重大节点暂停”默认关闭，只是播放偏好；人物从不等待玩家替他作决定。

## 已完成内容

- 十五岁至六十岁的 540 次月度更新与 541 份状态快照。
- 中学、大学 / 职业教育 / 学徒 / 直接工作、可选进一步学习、求职、职业发展、后期生活。
- 六个实践领域，职业不按 MBTI 硬锁。
- 43 个基础事件模板与 12 条具有延迟反馈的事件链；包含资源、家庭、表达、筛选、选拔错配、服从测试、协作、指标、晋升与转向。
- 四种可解释环境预设及十一项高级环境参数。
- 可复现种子、独立快照分支、按语义键寻址的外部随机扰动。
- 回放、阶段档案、真实记录图表、多维总结、十六人观察室、本地存档、收藏和导出。
- 响应式布局、键盘可操作控制、模态框焦点限制、减少动画偏好支持。

## 模型设定

模拟不是心理测评或现实命运预测。八维是独立的 0—100 游戏内部指数，不强制总和为 100，也不作为智商、职业能力、道德或人生总分。

八维与十六类型使用去均值向量及四功能序列模板的余弦相似度匹配。模板权重为 `1.00 / 0.70 / 0.35 / 0.10`，其余维度为零；接近阈值为 `0.065`。所有数值都是可调整的原创游戏参数，非官方百分制。算法版本 `centered-cosine/1.0`，生成版本 `functions-generator/1.0`，人生规则版本 `life-rules/1.0.0`。

每个月分配 160 小时自主时间，表示学习、实践、工作 / 求职、关系与恢复的可安排部分，并非整个月的全部时长。已有课程、练习、作品与工作经验单独进入发展档案。任务质量读取相关证据；性别、年龄与学校名只在具体筛选机制中影响机会，不直接改变原始作品质量。

模拟一次生成完整结果，播放器仅移动月份游标。分支复制指定月份的完整状态和待处理事件队列，之后重新决策。外部扰动由 `种子 + 月份 + 事件语义键` 寻址，新增一条分支事件不会打乱全部随机序列。

参考来源、借鉴边界、公式与局限见 [模型说明](.agentdocs/model-reference.md)。

## 已知限制

- 模型中的所有学校、机构和规则均为虚构，不代表任何地区或年份的统一政策。
- 六十岁是本版观察截止点，不代表退休年龄；没有模拟六十岁后的健康、养老或家庭变化。
- 关系网、行业、工资、生活支出、招募渠道和晋升轮次仍是简化模型；没有完整城市、宏观经济或投资系统。
- 地区首版用于身份和叙事背景，机会密度与资源差异主要由环境与家庭参数表达；地区名称本身不附带能力差异。
- 每月选择是可解释的效用规则，不能替代真实个体的心理过程；不调用大模型，也不要求外部 API Key。
- HTML 是可分享的年表格式；首版不提供独立图片年表与 JSON 导入。完整 JSON 可用于外部分析，包含未来月份。
- 存档属于当前浏览器与网站来源；本地预览和托管站点拥有各自独立的存储。清除网站数据会清空本地档案。
- 当前只兼容同一规则版本的存档与分支，后续版本迁移列入 TODO。
