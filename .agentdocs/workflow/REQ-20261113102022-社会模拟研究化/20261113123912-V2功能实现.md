## 目标、范围与参考边界

将原单人自动人生改为共享资源的多年龄社会。浏览器与 Node 共用类型和计算内核，首版交付可追溯、可复现的机制实验能力。

| 参考 | 实际采用 | 明确边界 |
| --- | --- | --- |
| PersonaOS | 原始倾向、有效画像、当前状态、记忆与受控修订分别保存 | 不使用文本人格生成、大模型反思和其有效性结论 |
| PsychSim | 主观概率、他人解释模型、有限前瞻 | 自身两步 Top3；对他人采用一层动机原型与共同奖励/softmax，不做完整递归求解 |
| FAtiMA | 事件经主观评价触发七种情绪，先衰减再注入，影响行为 | 简化评价模型，不实现全部情绪体系 |
| SimPaths | 人物家庭状态、制度结算、参数证据、样本外评估 | 不复制外国人口与制度参数，不继承现实验证结论 |

原始资料：[PersonaOS](https://arxiv.org/abs/2609.27417)、[PsychSim](https://ijcai.org/proceedings/2005/208)、[FAtiMA](https://arxiv.org/abs/2103.03020)、[SimPaths](https://microsimulation.pub/articles/00318/)。本项目公式、人格矩阵和数值均是本项目假设。

## 数据、单位与内核契约

`src/social/types.ts` 保存 World、Person、家庭、学校、企业、岗位、关系边、账户、债权、真实事件、人物观察、决策、检查点和报告类型。

- 八维为 `0—100`；大五、知识、实践、健康、心理状态为 `0—1`。两套画像独立采样并保存初始及有效版本。
- 金额全部整数分，账户非负，欠薪和学费等作为 claims；时间为半小时倍数。
- 动机六项归一化；价值规则、身份、人格、技能和机构评价分别保存。
- World 保存宏观输入、随机种子命名空间、期初账户来源、事件序号、待处理事项和干预历史。
- WorldEvent.truth 与 observations 分开。人物决策的签名不接收 World，只接自身状态、Observation 与参数。
- `stepWorld` 原地推进世界，避免每月全量深复制；`branchWorld` 深复制完整检查点。`projectLife` 为只读投影。
- 身份和人格不进入 `taskQuality`；无人格模型关闭偏好及人格可塑性影响。

公共入口：`src/social/index.ts`。V1 内核留在 `src/simulation/`，V2 复用原来的语义种子随机核心和八维生成/推导。

### 行动、认知与人物变化

- 每子步 `H=80(.5+.5health)`，照料先占用，再履行课程或工作。表达4小时、私下2小时、核实6小时必须有真实时间；不可行行动先排除。
- 两个人格适配器各自标准化并按矩阵参与偏好；人格不增加技能。八维均匀时偏好为零，无人格版本完全关闭此项。
- 即时效用将净现金、六类结果、努力和切换合并；已知税率参与收入预期。自我有限前瞻只推演局部状态与对方反应，不复制世界或偷看未来。
- 教育预期为十年折现的增量净收益，相对当前工作或剩余课程；放弃的工资、真实学费、主观完成率均计入。当前申请不重复扣未来费用。换校次月生效，知识保留、旧课程学分作废并记录。
- 表达处罚信念按机构、公开/私下及证据自信区间分开。只在收到可观察反馈时应用24月半衰期遗忘与 Beta 更新；无反馈不更新，传闻不计入处罚证据，同源事件去重。
- 他人模型只解释任务、安全、关系三种动机原型，可能判断错误，不读取对方人格。
- 任务质量按知识/实践、精力、实际工时和标准正态扰动；成功按 sigmoid 抽样，事件记录质量、难度、概率和结果，进入评价与学习反馈。
- 情绪七项按7.5日半衰期，在每子步新事件前衰减。精力与压力使用真实负荷、缺口、情绪和已收到支持。
- 策略季度变化限 ±.2、累计 ±2，机构特定与一般情境分开，迁移系数 .2。
- 人格可塑性默认关，年度至少24不同源事件、三情境、两对象；先登记候选与支持/反证，年度每维至多百分制一点。初始画像不变。

### 共享社会和资源

- 默认1000人、400家庭：100单人、100双成人、150双成人加一子女、50双成人加两子女与一祖辈。小人口模式按整数容量缩放，有下限，不视为人口样本。
- 三地区、六机构、三十六企业。学校三路径；企业有22初级、8熟练、2负责人岗位上限，不凭职级名称自动晋升。
- 企业按地区领域需求、声誉和价格竞争订单。按真实交付收到外部付款，材料、工资费用、运营和税分别结算；不付工资仍产生费用和应付。
- 期初企业六个月满编工资储备为显式外部资本禀赋，期初账记录来源；前三名股东从家庭现金前20%抽样。后续新企业必须实际出资，不能免费补充。
- 税后收入60%进入公共家庭账户，消费/照料、既有学费、可选支持按序支付；无钱产生缺口或欠款。物价同时作用生活与住房。
- 组织处罚倾向与证据响应独立。核实、返工、修正排入维护队列，消耗真实有薪工时，完成后才计修复。处罚占用真实余暇，余暇不足时转换有薪时间，减少可付工资。
- 关系邀请意愿与履约信任分开；半年不互动强度减半，非家庭上限24。每人每月最多传播三个不同已知岗位，接收去重且会失效。
- 实际合作匹配为二人（符合2—4边界），双方各支付时间；团队质量与移除成员贡献分开，外部记功另存。
- 企业政策季度强化，使用实际标准化利润/交付、流失与管理成本。干预锁定政策暂停该项学习。
- 死亡停止行动、观察、岗位、课程与未来个人承诺；原应付/应收保留。遗留现金进入原家庭，未扩展跨家庭继承规则。
- 月内各主体从同一状态观察和提交意向，随后统一执行；输入数组重排不改变结果。

月顺序落实为：外生更新 → 公布机会 → 生效上月承诺 → 四次观察/计划/执行/反馈 → 生产与结算 → 月末退出/季度更新/年度可塑性 → 指标与检查点。

## 实验、存储与产品界面

- 首实验三人格 × 两处罚 × 信念开关，共十二条件。各人格在共同外生条件下预热120月，从完整世界分支处理60月；默认30独立世界种子。
- 处理锁定处罚，关闭习惯与机构学习，独立检查信念机制。正确/错误报告、公开/私下/沉默、修复、返工、信念误差、流动、收入与经营均有指标。
- 世界是重复单位。分别在处理一年和实际终点，按种子配对计算政策效应、标准误与95%蒙特卡洛区间；正确/错误报告构成与离职/录用人次均纳入。一个重复不生成区间，不将不同人格画像的个体差解释为量表预测优劣。
- 敏感性默认64点六维拉丁超立方，按响应相关性筛前两项后追加25网格；只报告参数机制响应，非现实因果结论。
- 四结构：固定、仅信念、信念加策略、人格可塑性，共同预热快照且机构学习关闭。
- 外部预测接口按家庭固定70/15/15，并排除用于强制对齐的样本，提供未来波次过滤、Log Loss、Brier 与校准误差。接口不负责估计模型，也不能证明调用方提供的预测不存在泄漏。
- 浏览器 Worker 支持计算、分支、三类实验、进度与取消。IndexedDB 压缩存储年度完整检查点，内存只保留当前状态、密集观察和有限缓存。
- Node 支持 run / experiment / sensitivity / structure / validate，保存冻结 kernel、源码映射、SHA、参数与清单；完整流为 NDJSON，逐行处理背压。
- 并行实验每个世界重复独立工作线程，完整重复即时落盘。续跑校验规则、内核SHA、配置、十二条件完整性；拒绝混用旧规则数据。
- 默认界面提供配置、人物画像、人生时间线、发展档案、全社会分支、社会账本、参数证据、实验报告与本地档案。事实与人物已知信息分栏，回放只读取投影。
- 分支显示第一次不同选择、实际代价、一年/五年个体效应及群体溢出。
- V1 档案只读展示；只能用初始配置新建 V2，不从旧中途快照伪造社会。
- build 内联页面、样式、Worker，并保留 React、Lucide、stdlib 等完整第三方许可及源码许可段。

## 实施中的错误、修正与版本边界

保留失败证据，不将早期结果覆盖成最终通过：

1. 原生 `Math.exp/log` 在 Node 与 Chrome 出现约1ulp差异，使完整状态散列不同。改为锁定版本的 stdlib 纯 JS 数学实现；保持内部双精度，不通过显示性四舍五入掩盖差异。
2. 早期反馈在注入后立即衰减，已改为所有同起点决策后，先衰减旧情绪再注入；增加按实际任务结果重建情绪的断言。
3. 原学费分月四舍五入不能严格还原年费，已用整数分余数分配；原退学清除欠费已改为保留真实债权。
4. 修复先记成功后扣时间的早期实现已改为维护队列，实际完成才计数；企业欠薪费用与现金分离。
5. 最终资源检查发现表达/核实可能无足够时间仍列为候选，处罚可能在余暇用尽时消失，换岗可能留下旧问题，零生产可能生成作品，均已修复并新增四项回归。
6. 新增边界测试首跑两个失败源于夹具把下月事件设置为已过期、把所有信念（含工资反馈）都断言为零；修正时间及只检查旧机构表达信念后通过。未改生产机制迎合错误夹具。
7. 早期 `outputs/social-v2-formal*`、2.0版生命周期和旧敏感性报告是开发中产物，不作为2.1.1验收或正式研究；规则与SHA不匹配时禁止续跑混合。
8. 临时长期检查脚本最初在 /tmp 使用 .ts 被按CJS解释，顶层await报错；改为.mts后执行，与产品构建无关。
