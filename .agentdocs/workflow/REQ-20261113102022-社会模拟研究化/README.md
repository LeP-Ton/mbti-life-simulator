## 用户已确认的目标与范围

- 不接大模型，React / TypeScript、本地浏览器、Web Worker、Node 和离线 HTML 共用计算规则。
- 多年龄人物共享社会；家庭、企业、学校和政府有独立账本，招生与岗位按真实名额竞争。
- 人物用自身观察、信念、有限前瞻和概率选择行动，反馈改变信念与策略；基础人格默认固定。
- 八维、大五、无人格效应独立对照，人格不直接产生知识或原始任务质量。
- 整个社会快照与分支、十二条件实验、敏感性、结构对照、可审计数据导出。
- V1 人生保留为只读档案，只允许复用初始人物配置新建 V2。
- 首版交付机制实验能力。取得相应数据后再估计参数、实施留出验证，不能凭内部实验声称现实预测能力。

## 当前有效结论

- 实现入口为 `src/social/index.ts`，默认产品入口为 `src/SocialLab.tsx`，Node 入口为 `scripts/experiment.ts`。
- 参考分工已经落实：PersonaOS 的分层与受控更新、PsychSim 的有限信念和前瞻、FAtiMA 的评价与情绪、SimPaths 的状态转移与独立验证。未继承其框架运行依赖、文本推理或已发表的有效性结论。
- 旧研究草案中的“首个研究对象未定、内核未实施”已被本次用户确认方案替代。首个实验聚焦组织处罚规则如何经信念影响表达、修复、流动与经营。
- 所有公式、矩阵、人口分布和制度数值是合成建模假设。小规模流程验证和默认千人正式实验属于不同验收范围。
- 详细实现、实际验证、简化假设与未验证项统一记录在[实施阶段](20261113123912-V2功能实现.md)，本入口不重复公式与文件明细。
