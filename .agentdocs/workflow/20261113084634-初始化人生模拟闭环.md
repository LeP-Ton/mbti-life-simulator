# 初始化《MBTI 人生模拟》完整闭环

## 背景与目标

- 会话：会话-1 起，根据用户提供的 V3.0 开发需求创建可玩的中文版网页游戏。
- 初始目录仅有空 Git 仓库，没有既有工程或有效项目文档。
- 实现从十五岁至六十岁自动运行、原因回看、阶段档案、环境分支与多人物对照。
- 开发分支：`codex/mbti-life-simulator`；原始分支为未提交的 `main`。

## 约束与原则

- React、TypeScript、Vite；浏览器本地规则模拟，不需要大模型与 API Key。
- 先有八维与人物，再与任务和环境互动；禁止按 MBTI 固定职业。
- 身份、基础画像、知识实践、动态状态和外界评价分离。
- 播放速度不参与模拟；分支复制真实快照与事件队列，共用外部随机键。
- 用户数据保存在浏览器 IndexedDB，导出不依赖服务端。
- 不新增测试框架，使用 Node 内置测试与 tsx。

## 代码变更

- `src/simulation/types.ts`：明确人物、环境、档案、动态状态、事件、快照与存档数据契约。
- `src/simulation/personality.ts`：十六种四功能序列、可调匹配参数、目标类型采样和接近类型。
- `src/simulation/random.ts`：由种子、月份与语义键寻址的确定性随机函数。
- `src/simulation/config.ts`：四个原创环境、六个知识实践领域、阶段与职业资料。
- `src/simulation/decisions.ts`：选项效用、受约束的时间分配、任务与考试证据评价、独立偏见门槛。
- `src/simulation/events.ts`：43 个模板与 12 条链的元信息。
- `src/simulation/engine.ts`：月度状态机、机会、发展档案、因果队列、真实分支与多维总结。
- `src/components/` 与 `src/App.tsx`：完整观察界面、配置、回放、阶段档案与平行人生。
- `src/lib/`：版本化 IndexedDB、本地错误提示、HTML 转义和数据导出。
- `src/styles.css`：纸色与鼠尾草绿的响应式视觉，原创 SVG 人物与人生插画。
- `README.md`、`TODO.md`、`AGENTS.md`、`CLAUDE.md`：运行、边界、长期规范与后续扩展。

## 关键实现与修正

- 任务质量公式不接收身份参数；筛选器单独读取具体偏见规则，保留筛选前的作品证据。
- 初版测试发现早期分支快照共享引用，已经改成独立深复制；同环境续跑与原人生完全一致。
- 探索与转向通过队列在实际月份转移实践时间，不在反馈时补发未投入的经验。
- 晋升校验原组织与当前岗位任职月份，防止离职后在新岗位兑现旧考核。
- 快照保存环境变更历史，嵌套分支与历史导出能读取当时环境。
- 模拟资料与视觉播放解耦；本地完整生成后任意回放不会重抽剧情或类型。

## 关键风险与已知限制

- 模型不是心理测量或命运预测，工资、行业、学校与关系模型均简化。
- 一份完整人生约 2 MB 文本；十六人使用 IndexedDB，避免 localStorage 容量限制。
- 清除网站数据会删除档案；本地开发与托管站点存储彼此独立。
- 版本迁移、JSON 导入、独立图片年表、六十岁后观察与更复杂家庭仍在 TODO。
- 本机沙箱限制了 esbuild 读取祖先目录和 Git 元数据写入，依赖安装、构建与 Git 操作通过授权执行通道完成。
