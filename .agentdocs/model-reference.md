# 八维、评分器与人生规则说明

核对日期：2026 年 11 月 13 日。以下参考用于术语与呈现结构，不等于本游戏经过心理测量验证。

## 借鉴来源与边界

| 来源 | 借鉴内容 | 不借鉴的部分 |
| --- | --- | --- |
| [Myers & Briggs Foundation：类型动力学与心理过程](https://www.myersbriggs.org/unique-features-of-myers-briggs/type-dynamics-processes/) | 核对内外倾与感觉、直觉、思维、情感的术语和基本描述 | 不宣称网站提供了本游戏的百分制八维、人生映射或余弦算法；页面对第三功能方向存在开放表述，本游戏按需求选用明确的常见四功能序列作为游戏模板 |
| [Sakinorva Cognitive Functions Test](https://sakinorva.net/functions) | 八功能画像、同时呈现多个评分方法的结构；参考页明确说明题目与算法自有 | 不复用原题、原始分数或任何原算法，不标记为官方 MBTI 测评 |
| [Keys2Cognition](https://www.keys2cognition.com/assessment.html) | 四十八项行为描述与认知过程画像的组织方式 | 不搬运题目、不换算站点分值、不把熟练度措辞直接当作职业能力 |
| [Michael Caloz](https://www.michaelcaloz.com/personality/) | 解释认知功能与展示接近类型的方式；页面说明其使用自有题目、模型与算法 | 不把其类型匹配分当作八维百分数，不复用其权重或题库 |

所有界面说明、事件与参数均为原创。首版没有问卷，更没有必须完成的测评流程。

## 独立评分器

`inferMbtiFromFunctions(scores)` 在 `src/simulation/personality.ts` 中实现。

1. 验证八维完整、有限并位于 0—100；缺失、非法或全部相同返回“类型待区分”。
2. 十六个模板分别使用配置中的常见四功能序列，权重为 `1.00 / 0.70 / 0.35 / 0.10`，其余四维为零。
3. 人物和每个模板分别减去各自八维均值，再计算余弦相似度。
4. 全部十六个模板排序。第一名是主匹配，保留前三名及原始功能分数的独立排序。
5. 前两名差小于 `0.065` 时提示接近。并列使用固定模板次序，同时保留并列提示。
6. 区分度是前两名相似度差，不是心理判断准确率。不能为凑出类型修改原始八维。

生成器先采样独立八维向量，再验证是否与目标类型相符。个体的基线、幅度与功能扰动由种子决定，没有固定总点数。

## 数据分层

- 基础画像：八维、生成器版本、确定的类型结果与算法版本。
- 身份环境：性别、地区、家庭资源、家庭期待与可调整规则。
- 发展档案：分领域知识接触、练习、考试熟练度、作品、资格、实际工作月份与贡献。
- 动态状态：精力、压力、兴趣、自主、满意度、信任、表达意愿、关系与经济储备。
- 人生记录：结构化条件、候选行动、选择、原始表现、评价、直接影响、机会来源和前因。

六个领域是知识与实践档案的组织方式，不是替代八维的天赋表。年龄、经验、雇主和学校名称不为八维涨点。

## 模拟映射与平衡参数

- 时间：每月 160 小时自主时间，人物在学习、实践、工作或求职、关系与恢复之间安排。探索和转向从旧任务转移时间，不补发空白经验。
- 选择：先生成可行选项，按八维倾向、资源、兴趣、已获反馈、状态与环境的效用选择；所有重大路口都能自动完成。
- 考试：读取课程接触、题型练习、精力与压力；不由某一项功能分数直接给出答案。
- 项目：`evaluateTask` 只接受相关知识、实践、状态、工具与支持等证据。它不接收性别、年龄、学校、姓名或八维。
- 评价：学历、性别与年龄偏见可先挡住机会；标准答案、短期指标、异议回应与任务一致性分别参与评价和后续反馈。
- 成长：学习与动手时间改变档案，环境反馈改变信任、表达与策略，不随机切换人格。
- 资源：通过训练可及性、经济缓冲、家庭支持与时间成本影响经历；地区首版不直接改变机会参数。
- 结尾：分别叙述获得、付出和未关闭的可能，不设置人生总分。

上述均为明确标注的简化游戏规则，未声称来自参考站点的测评结论。

## 因果与可复现

- 月份统一从 0 至 540；月份 0 对应十五岁起点。
- 外部随机数用 `种子 | 月份 | 语义键` 寻址，不消费一个全局随机序列。
- 人物选项的扰动使用选项自己的键；新增候选项不会重新排列所有无关随机数。
- 延迟反馈使用队列，保留前因事件 ID、到期月份与必要证据。
- 分支复制真实快照及既有记录，支持嵌套环境历史；原记录与分支不共享可变快照。
- 回放只读取预生成记录。相同环境的中途续跑必须与原人生剩余记录完全一致。

## 当前局限

职业、关系和经济模型是轻量近似；环境变化被视为之后所有学校或组织规则的变化，不模拟搬迁与机构逐个改革成本。基础画像在首版固定，人物兴趣可变。没有健康、婚姻、真实政策、宏观经济、城市人口或现实心理预测。
